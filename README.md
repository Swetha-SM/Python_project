# 💰 FinSmart – Intelligent Household Finance Management and Budget Planning System

## 📌 About the Project

FinSmart is a web-based intelligent household finance management system designed to help users manage their monthly income, plan budgets, track daily expenses, and achieve their savings goals.

The application automatically allocates the user's salary into different expense categories, monitors daily spending, and provides personalized financial suggestions. Its main objective is to prevent unnecessary spending and encourage better financial habits through intelligent budget analysis and predictive alerts.

## 🎯 Key Features

- **User Authentication:** Secure registration and login using JWT authentication.
- **Smart Budget Planner:** Automatically allocates monthly income into categories such as rent, groceries, transportation, healthcare, utilities, entertainment, and savings.
- **Expense Tracker:** Records and categorizes daily expenses with payment details.
- **Daily Expense Reminder:** Sends a daily reminder at 8:00 PM to update transactions.
- **Virtual Bank:** Simulates bank balance and transaction management.
- **Bill Reminders:** Provides reminders for upcoming electricity, water, rent, insurance, and other payments.
- **AI Financial Advisor:** Analyses spending patterns and provides personalized financial suggestions.
- **Smart Financial Guardian:** Predicts month-end spending, identifies overspending risks, calculates safe daily spending limits, and generates alerts to protect savings goals.
- **Financial Reports:** Generates daily, weekly, monthly, and annual reports.
- **Interactive Dashboard:** Displays income, expenses, remaining budget, savings progress, and visual analytics.

## ⭐ Unique Feature – Smart Financial Guardian

Unlike traditional expense trackers, FinSmart predicts future spending based on the user's current spending pattern.

It calculates:
- Average daily spending.
- Predicted month-end expenditure.
- Expected overspending amount.
- Estimated budget exhaustion date.
- Recommended daily spending limit.
- Monthly savings goal status.

When overspending is predicted, the system generates a Financial Guardian Alert with personalized recommendations to help users control their expenses and protect their savings.

## 🔄 Application Workflow

1. User registers and logs into FinSmart.
2. Enters monthly salary, fixed expenses, and savings goal.
3. System automatically generates a personalized monthly budget.
4. User records daily expenses.
5. Daily reminders encourage users to update transactions at 8 PM.
6. System analyses expenses and updates the remaining budget.
7. Smart Financial Guardian predicts future spending and detects overspending risks.
8. Personalized alerts and suggestions help users achieve their savings goals.

## 🚀 Project Objective

To develop an intelligent financial assistant that goes beyond basic expense tracking by providing automated budget planning, predictive spending analysis, and personalized financial guidance for better household financial management.
